## 1. 포트원 문의 문안 (복사해서 포트원 콘솔 1:1 문의에 붙여넣기)

**제목:** PayPal 해외 결제(영어·일본어 사이트) 연동 관련 문의

안녕하세요. 대국민스토어(사업자, 상점 ID 끝자리 …b4c3142c3)입니다.
한국 사업자 명의로 영어·일본어 디지털 콘텐츠(사주 리포트, 1회성 판매)를 해외 개인 고객에게 PayPal로 판매하려고 합니다.
현재 PayPal 테스트 채널로 USD 결제창과 결제 조회(currency=USD, amount.total=399)까지 확인했고, 실운영 채널 개설 전에 아래를 확인하고 싶습니다.

1. **신청 절차:** PayPal 일반결제(SPB)로 "전자결제 신청"을 진행하면 되나요? 사업자 PayPal 비즈니스 계정(Merchant ID 보유)을 그대로 연결할 수 있나요? 필요한 서류와 심사 기간은 어느 정도인가요?
2. **계정 유형:** 연결하는 PayPal 계정이 한국 사업자 명의 비즈니스 계정이어도 되나요? 개인 명의 계정이면 제약이 있나요?
3. **포트원 수수료:** PayPal 결제에 포트원이 별도로 받는 수수료(결제 건당·월정액·최소 수수료)가 있나요?
4. **소액결제 요율:** 디지털 콘텐츠 소액결제(약 $3~4, ¥600 안팎)에 PayPal 소액결제 요율이 적용되나요? 적용 조건이 있나요?
5. **엔화(JPY) 지원:** JPY 결제를 지원하나요? 최소 결제 금액이나 소수점 처리(엔은 최소 단위가 1엔) 제약이 있나요?
6. **정산·환율·보류금:** 정산 주기(PayPal → 한국 계좌), 정산 통화(USD 보유 후 원화 환전 여부, 환전 수수료), 보류금(Reserve) 정책이 어떻게 되나요?
7. **금액 단위:** USD는 센트 단위(399 = $3.99), JPY는 엔 단위(580 = ¥580)로 `totalAmount`를 보내는 게 맞나요? 결제 조회 시 `currency`와 `amount.total`이 같은 단위로 내려오나요?

추가로 환불(전액·부분)이 PayPal 채널에서도 포트원 콘솔·API로 모두 가능한지, 분쟁(Dispute) 발생 시 처리 흐름도 알려주시면 감사하겠습니다.

## 2. 단가·마진 계산 (AI 비용 실측 반영)

**측정 조건:** 실제 Anthropic API로 6장 전체를 생성(모델 claude-sonnet-5, 입력 $2 / 출력 $10 per 1M 토큰 기준). 1992.3.14 14시 여성 샘플 1건.

| | 영어 | 일본어 |
|---|---|---|
| API 호출 수 (6장 + 재시도) | 6회 | 7회 |
| 입력 / 출력 토큰 | 15,158 / 6,916 | 18,468 / 10,589 |
| **AI 비용 (리포트 1건)** | **약 $0.10** | **약 $0.14 (약 ¥23)** |
| 생성 시간 | 약 23초 | 약 53초 |
| 첫 측정(프롬프트 수정 전) | $0.130 | $0.196 (한 장이 금지어로 실패) |

**1건당 남는 금액 (포트원 수수료·세금·환전 제외, PayPal 한국 해외수취 요율 기준)**

| | 영어 $3.99 | 일본어 ¥580 |
|---|---|---|
| PayPal 일반 요율 (4.40% + 고정) | -$0.48 | -¥66 |
| AI 비용 | -$0.10 | -¥23 |
| **남는 금액** | **약 $3.41 (86%)** | **약 ¥491 (85%)** |
| (소액결제 요율이 적용되면) | 약 $3.62 | 약 ¥518 |

- 환율은 7월 말 기준($1≈1,424원, 100엔≈888원)이라 실제와 다를 수 있어요. 수수료 요율은 조사 당시 값이고, 포트원 수수료·환전 비용·보류금은 문의 답변 후 다시 계산해야 해요.
- 재시도가 늘거나 고객이 같은 장을 다시 열면 AI 비용이 조금 늘 수 있어요(이미 만든 장은 캐시에서 보여줘서 다시 안 만들어요).

## 3. 세금·법률 확인 목록 (세무사·법률 전문가에게 확인할 것)

일반 정보이며 사장님 상황에 맞는 확정 답이 아니에요. 아래 질문을 그대로 전달하면 돼요.

**세무**
1. 한국 사업자가 해외 개인 고객에게 PayPal로 판매하는 디지털 콘텐츠 매출의 **한국 부가가치세** 처리(영세율 적용 여부, 신고 방법)
2. **일본 소비세:** 일본 소비자에게 전자서비스를 파는 해외 사업자는 매출 규모에 따라 소비세 등록·납부 의무가 생길 수 있다고 알려져 있어요. 현재 규모에서 의무가 있는지, 기준(기준기간 매출 등)이 무엇인지
3. **미국 판매세(주별 sales tax):** 소액 판매 단계에서 걱정할 기준(경제적 연관성 기준 매출)이 있는지
4. PayPal로 받은 **외화(USD) 보유·환전**의 환차손익 처리와 외화 수입 신고
5. PayPal 수수료·AI 비용의 비용 처리

**법률·표시**
6. 일본어 사이트의 **특정상거래법 표기**(판매업자 정보, 가격, 결제·환불 조건 표시)가 충분한지 — 현재 약관 페이지에 이미 넣어 두었어요
7. 영어·일본어 **약관·환불·개인정보처리방침** 검토(특히 "디지털 콘텐츠는 제공 후 환불 제한" 문구와 일본·미국 소비자 보호법 충돌 여부)
8. 일본어 사이트 문구의 **원어민 감수**(약관과 리포트 샘플)
9. 개인정보 국외 처리 안내(서버·AI 처리 위치) 문구 확인
