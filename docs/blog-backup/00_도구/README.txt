1) 데이터 받기:   python fetch_2027.py <띠key> "<이미지폴더>\data.json"
2) 사진 만들기:   python make_blog_images.py "<이미지폴더>\data.json" "<이미지폴더>"
   (PYTHONIOENCODING=utf-8, 글꼴은 윈도우 기본 batang·malgun)
3) 순서:          queue.json (위에서부터, done=초안 만든 날짜)

초안 규칙(11/18 사장님 '올릴 순서 메모 만들지 말고 파일명에 1순위', '바로복사 파일만 남기자'):
  원본(저장소, [[주소:…]] 자리표시): 00_도구\원본\<YYYY-MM-DD>\<N>순위_<제목>.txt
  사진(저장소): <YYYY-MM-DD>\<N>순위_<제목>_이미지\
  완성본(이 컴퓨터만, 주소 채움): fill_links.py가 <YYYY-MM-DD>\<N>순위_<제목>.txt 로 만든다
  → 사장님 날짜 폴더에는 'N순위_제목.txt'와 그 사진 폴더만 보인다. 올릴_순서 메모는 만들지 않는다.
  (정렬·카테고리·사진 장수는 각 txt 맨 위에 적는다. 1순위 = 홈판용 먼저, 2순위 = 띠별 몇 시간 뒤)
태그는 한 줄에 하나씩, 사이트 링크 끝에 ?from=blog. 각 txt 맨 위에 [주제] 주제 선택 안 함 (11/20 사장님: 조회수 가장 높은 총정리 글이 주제 없음. 네이버 주제 목록에 운세 칸이 없음). (AI 도움 표기는 11/16부터 넣지 않음)

4) 주소 채우기:   python fill_links.py "<날짜 폴더>"
   (11/18~) 00_도구\원본\<날짜>의 원본을 읽어 <날짜> 폴더에 같은 이름 완성본을 만든다. 완성본 txt가 저장소에 안 올라가게
   이 컴퓨터의 .git/info/exclude에 'docs/blog-backup/20*/*.txt'를 자동으로 넣는다(.gitignore를 고치면 Vercel 빌드가 돌아서).
   (~11/17 옛 방식) 초안의 [[주소:제목 일부]]를 초안 폴더(docs/blog-backup)의 '사주랩 블로그 글 주소.txt'(로컬 전용, RSS로 자동 갱신, 없으면 바탕화면 블로그 바로가기로 새로 만듦)의 주소로 바꿔
   같은 폴더에 '★바로복사_<원래 이름>.txt'를 만든다. 사장님은 이 파일만 열어 복사하면 된다.
   ★바로복사 파일은 .gitignore라 저장소에 안 올라가므로 초안을 받은 컴퓨터에서 한 번 실행.
   (11/16 사장님: '여기에 주소 붙여 넣기' 없이 그냥 복사하게)
