사용자가 여러 컴퓨터(노트북/데스크톱)를 넘나들며 작업할 때, 매번 손으로 폴더를 복사하거나 여러 단계를 반복해야 하는 워크플로우를 제안하면 "너무 귀찮은데"라는 명시적 불만이 나왔음 ([[project-shorts-auto]] 세팅 중, 2026-08-22).

**Why**: USB로 폴더 여러 개를 매번 옮기라고 제안했다가 반발을 샀고, 결국 git+GitHub 자동 동기화로 전환해서야 만족함. 사용자는 "USB 방법 말고 다른 방법 없어?"처럼 대안을 스스로 요구하기도 함.

**How to apply**: 여러 환경/컴퓨터에 걸친 반복 작업을 설계할 때는 처음부터 완전자동 또는 최소클릭 옵션(예: git push/pull, 배치 스크립트, 스케줄러)을 우선 제안하고, 순수 수동 반복 작업은 최후의 수단으로만 제시할 것. 이미 수동 방식을 제안했는데 불만이 나오면 즉시 자동화 대안을 다시 제시할 것.
