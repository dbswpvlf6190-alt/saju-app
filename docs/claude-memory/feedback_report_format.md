실적·현황·작업 결과를 사용자에게 보고할 때는 대화체 나열이 아니라 **보고서 형식**으로 쓴다.

**Why:** 사용자가 반복해서 요구했다. 10/13 "진짜 회장님한테 보고서 올리는 것처럼 하자 너무 가독성이 없네", 10/19 "보고서 형식으로 항상 보고해". 줄글·긴 설명은 가독성이 떨어진다고 본다. 관련: [[project_saju_app]], [[project_shorts_auto]].

**How to apply:**
- 구성: 제목(날짜·범위) → ① 한눈에 보기(영역별 상태 표 + 한 줄 평가) → ② 영역별 소제목(수치·사실 위주, 짧은 불릿) → ③ 확인하지 못한 것(로그인 필요 등 이유와 함께) → ④ 결론 → ⑤ 다음 할 일(사장님/제가 구분, 우선순위 번호).
- 수치는 출처 시점(기준일)을 붙이고, 추정은 "(추정)"으로 표시. 확인 못 한 항목은 지어내지 말고 따로 표시한다.
- 전문 용어는 풀어서 쓴다. 군더더기 설명은 줄인다.
- 길게 남길 가치가 있는 보고서(전략·결과)는 Artifact로 게시해 링크를 준다(이전 10/13 보고서 방식). 일상 현황은 대화창에 보고서 형식으로 쓴다.
