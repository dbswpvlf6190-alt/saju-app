**파일을 넘길 때:** 전체 경로를 먼저 적고 `reveal_path`로 탐색기에서 열어 준다. 칸에 넣을 값은 칸마다 코드블록 하나씩, 한 단계씩 안내한다(11/11 "이미지가 어디있는지 알려줘야지", "하나씩 진행하자", "입력칸에 뭘 넣어야하는지 리스트로").

**블로그 글(사주랩 운세연구소, 기존 네이버 계정, 주소는 바탕 화면 '사주랩 운세연구소 블로그' 바로가기):** 키워드 나열·"쉽게 풀어 드리는" 같은 AI 말투·가운뎃점(·) 남발 금지 — 운영자 1인칭, 실제 사실(창원에서 사주랩을 만드는 사람, 손님이 묻는 질문, 원칙)로 쓴다. 지어낸 경력 금지. 네이버는 본문 가운데 정렬로 올리니 초안은 처음부터 짧은 줄로. 글 끝에 AI 도움·사람 검수 표기. 하루 1~2편. **태그는 한 줄에 이어 쓰지 말고 한 줄에 하나씩**(`[태그] 하나씩 따로 넣기` 아래 `  #태그`), 안내할 때도 태그마다 코드블록 하나씩. 본문 사이트 링크 끝엔 `?from=blog`(11/13부터, 블로그 효과 측정)(11/13 "메모장에 태그가 하나로 이어져 보이거든").

**초안 폴더 규칙(11/12 사장님 "날짜별로 관리, 파일명에 제목과 날짜"):** `클로드코드1\사주랩_블로그_초안\<YYYY-MM-DD>\<YYYY-MM-DD>_<글 제목>.txt` + 같은 이름 `_이미지` 폴더(사진·data.json), 날짜 폴더마다 `<날짜>_올릴_순서.txt`. 블로그 프로필·커버는 `00_블로그_설정`. 만들 도구(11/13부터 OneDrive로 옮겨 두 컴퓨터 공유): `클로드코드1\사주랩_블로그_초안\00_도구\fetch_2027.py`, `make_blog_images.py`, 순서 `queue.json`(done=초안 만든 날짜), 사용법 `README.txt`. 옛 `C:\saju-reports\blog`는 쓰지 말 것.

**Why:** 사장님이 첫 소개글을 "너무 AI같고 신뢰가 안가"라고 함, 파일 위치를 안 알려줘서 크게 짜증냄. 네이버 도메인은 Claude 브라우저(크롬 확장·내장 둘 다)에서 차단돼 네이버 화면 조작은 사장님 몫. **How to apply:** [[project_y2027_seo]] 블로그 초안 만들 때마다 적용.
