## 2. 상담권(Pass)
결제하면 상담권 1장을 만든다. **로그인 없이** 쓰는 것이 기본이다(50대 이상 마찰 최소화).

| 필드 | 설명 |
|---|---|
| `id`, `token` | 상담권 열기 링크 `/consult/{id}?k={token}`. 결제한 브라우저에는 httpOnly 쿠키도 같이 저장(기존 `orderAccess` 서명 방식 재사용) |
| `ownerProfile` | 주인 생년월일·성별·양음력(기존 birthInput 형식) |
| `family[]` | 가족 프로필(관계·이름 선택·생년월일), 상품별 최대 인원 |
| `creditsLeft` | 횟수형(5회·15회) |
| `unlimitedUntil`, `dailyCap` | 기간형(30일·90일, 하루 20개) |
| `source` | web / toss, `orderPaymentId` 연결 |
| `giftFrom` | 선물이면 보낸 사람 표시(이름만) |

- 링크를 잃어버렸을 때를 대비해 **"내 카톡으로 보내기"** 버튼(공유 시트)과 **카카오 로그인 연결(선택)**을 둔다. 기존 User(kakaoId)와 연결한다.
- **선물하기(웹)**: 사는 사람은 받는 분 이름만 적는다. 받는 분이 링크를 처음 열 때 생년월일을 넣는다.

## 3. AI 상담 흐름
1. 화면 위에 **내 사주 요약 카드**(일간 타입·오행·2027년 한 줄)
2. **추천 질문 버튼**: 2027년 돈 들어오는 달 / 자녀·가족 / 일·사업 / 이사·매매 시기 / 남편·배우자 / 조심할 달
3. 질문 입력(최대 300자) → 답변은 **400~700자, 존댓말, 큰 글씨**. 끝에 "다음에 물어볼 만한 것" 2개를 제안
4. **기억**: 사주 계산 결과 + 가족 사주 + 최근 대화 6턴 + 지난 대화 요약 1개
5. 남은 횟수와 기간을 늘 보여 준다. 다 쓰면 다음 상품 제안(15회 → 30일 무제한)

**모델·비용:** 기존 풀이와 같은 `claude-sonnet-5`. 질문 1개 상한은 출력 900토큰, 입력 약 3천 토큰(약 20~30원).
- 상담권 1장의 AI 비용 상한: 5회형 300원, 15회형 1,000원, 30일형 3,000원(하루 20개 × 상한)
- 초과하면 그날은 멈추고 "내일 다시"로 안내한다.

## 5. 결제·환불 (웹)
- 기존 포트원(KG이니시스) 흐름에 새 상품 코드만 추가한다. 금액은 서버 카탈로그만 믿는다.
- **청약철회 고지(전자상거래법):** 결제 전 "디지털 콘텐츠는 이용을 시작하면 청약철회가 제한될 수 있어요"에 동의를 받는다.
- **환불:** 사용하지 않은 상담권은 7일 안 전액 환불. 사용한 뒤에는 남은 횟수·기간만큼 비례 환불(약관 개정 필요, 사장님 확인).
- **테스트:** 미리보기 배포 + 포트원 **테스트 채널**로 결제 → 상담권 발급 → 차감 → 환불까지 무료 검증.
