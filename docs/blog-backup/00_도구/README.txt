사주랩 블로그 초안 도구 (두 컴퓨터 공유, OneDrive)

1) 데이터 받기:   python fetch_2027.py <띠key> "<이미지폴더>\data.json"
2) 사진 만들기:   python make_blog_images.py "<이미지폴더>\data.json" "<이미지폴더>"
   (PYTHONIOENCODING=utf-8, 글꼴은 윈도우 기본 batang·malgun)
3) 순서:          queue.json (위에서부터, done=초안 만든 날짜)

초안 규칙: 날짜 폴더 <YYYY-MM-DD>\<YYYY-MM-DD>_<제목>.txt + 같은 이름 _이미지 폴더, <날짜>_올릴_순서.txt
태그는 한 줄에 하나씩, 사이트 링크 끝에 ?from=blog. (AI 도움 표기는 11/16부터 넣지 않음)

11/16 결정: 이미 올린 글은 고치지 않는다. 새 글부터 제목에 대표 나이 3개(예: 62년생 74년생 86년생),
본문에 [나이별로 보면](천간별 차이), 맨 끝 [함께 보면 좋은 글]에 총정리 글 3편.
블로그 글 주소는 이 공개 저장소에 넣지 않는다 — 바탕화면 '사주랩 블로그 글 주소.txt'(OneDrive)에서 복사.

11/18 결정(상위 블로그 글 1,531편 조사 → 사장님 승인): 새 글은 이 구조로 쓴다.
- 본문+표 2,200자 이상(공백 제외). 1~3위 글 중앙값 2,362자, 우리 옛 글 약 790자였음
- 맨 앞 '한눈에 보는 답' 2~3줄(좋은 달·조심할 달·삼재 여부)
- 소제목은 '▶ 제목' 줄로 쓰고 사장님이 인용구로 넣음(5~8개)
- 표 2개: 출생년도·간지·만 나이 표, 열두 달 흐름표 → 같은 폴더 '<글 이름>_표.html' (표 자리는 본문에 '(표 ①)')
- 띠별 글 제목: '2027년 ○○띠 운세 한눈에, 4개 출생년도(예: 53년생 65년생 77년생 89년생) 한 줄'
- 나이별 문단은 5~6개 출생년도 모두, '자주 묻는 질문' 3개, '잘 쓰는 방법 세 가지'
- 시리즈 문구('2027 띠별 운세 시리즈 ○번째 글') + 앞 글 2편 링크 + 다음 글 예고
- 정렬 비교 시험(11/18~): 띠별 글은 왼쪽 정렬·문단형, 총정리·모두에게 해당되는 글은 가운데·짧은 줄. 1주 뒤 순위로 판단
- 띠 12편이 끝나면 queue의 년생별 글('63년생 2027 운세' 등)을 같은 구조로 이어 간다
- 하지 않음: AI 말투, 지어낸 경험, 겁주기·건강 단정, 이미 올린 글 고치기

4) 주소 채우기:   python fill_links.py "<날짜 폴더>"
   초안의 [[주소:제목 일부]]를 초안 폴더(docs/blog-backup)의 '사주랩 블로그 글 주소.txt'(로컬 전용, RSS로 자동 갱신, 없으면 바탕화면 블로그 바로가기로 새로 만듦)의 주소로 바꿔
   같은 폴더에 '★바로복사_<원래 이름>.txt'를 만든다. 사장님은 이 파일만 열어 복사하면 된다.
   ★바로복사 파일은 .gitignore라 저장소에 안 올라가므로 초안을 받은 컴퓨터에서 한 번 실행.
   (11/16 사장님: '여기에 주소 붙여 넣기' 없이 그냥 복사하게)
