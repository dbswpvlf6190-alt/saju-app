2026-11-18 사장님: "숫자가 나오면 어렵다는 생각이 드는 거 같애". 비유 4종 제안 후 "만원으로 하자"(이익률 비유를 100원 → 만 원으로).

**Why:** 시청자가 숫자를 들으면 어렵다고 느껴 이탈한다고 본다. 만 원이 생활 감각에 더 가깝다.

**How to apply:**
- 롱폼·쇼츠 대본 모두: 숫자는 카드·자막에만 두고, 목소리는 비유로(영상의 큰 비유, 시험 점수, 만 원 기준, 계단). 한 장면에 숫자는 하나.
- 비유 숫자도 실제 계산과 맞추고 근거를 fact_check에 남긴다.
