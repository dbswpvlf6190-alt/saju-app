**파일을 넘길 때:** 전체 경로를 먼저 적고 `reveal_path`로 탐색기에서 열어 준다. 칸에 넣을 값은 칸마다 코드블록 하나씩, 한 단계씩 안내한다(11/11 "이미지가 어디있는지 알려줘야지", "하나씩 진행하자", "입력칸에 뭘 넣어야하는지 리스트로").

**블로그 글(사주랩 운세연구소, 기존 네이버 계정, 주소는 바탕 화면 '사주랩 운세연구소 블로그' 바로가기):** 키워드 나열·"쉽게 풀어 드리는" 같은 AI 말투·가운뎃점(·) 남발 금지 — 운영자 1인칭, 실제 사실(창원에서 사주랩을 만드는 사람, 손님이 묻는 질문, 원칙)로 쓴다. 지어낸 경력 금지. 네이버는 본문 가운데 정렬로 올리니 초안은 처음부터 짧은 줄로. 글 끝에 AI 도움·사람 검수 표기. 하루 1~2편. **태그는 한 줄에 이어 쓰지 말고 한 줄에 하나씩**(`[태그] 하나씩 따로 넣기` 아래 `  #태그`), 안내할 때도 태그마다 코드블록 하나씩. 본문 사이트 링크 끝엔 `?from=blog`(11/13부터, 블로그 효과 측정)(11/13 "메모장에 태그가 하나로 이어져 보이거든").

**초안 폴더 규칙(11/13 사장님 "앞으로 2번 경로(GitHub)로 진행")**: 기본 위치는 **`C:\saju-app\docs\blog-backup\<YYYY-MM-DD>\`** (`<날짜>_<글 제목>.txt` + 같은 이름 `_이미지` 폴더(사진 4장·data.json) + `<날짜>_올릴_순서.txt`). 도구는 `docs\blog-backup\00_도구`(fetch_2027.py·make_blog_images.py·queue.json·README.txt). **만들기·[올림] 표시·queue 갱신은 worktree(`C:\saju-app-y2027` 등, origin/main 기준 새 브랜치)에서 하고 main에 푸시**(docs만이라 Vercel 빌드 없음), 그다음 `git -C C:\saju-app pull --ff-only origin main`으로 사장님 폴더에 바로 보이게 한다. `C:\saju-app`에서 직접 파일을 고치지 말 것(자동화 공유 체크아웃). 사장님에게 줄 때는 `C:\saju-app\docs\blog-backup\<날짜>` 경로 + reveal_path. OneDrive `클로드코드1\사주랩_블로그_초안`은 11/13까지의 옛 위치(더는 갱신 안 함), `C:\saju-reports\blog`도 옛것. 공개 저장소라 초안에 개인 아이디·연락처를 넣지 않는다(본문엔 사이트 주소만).
