2026-11-16 사장님이 09 종부세 썸네일 시안 비교 후 "지금이 나은 거 같애. 후킹이라는 게 정보를 많이 주기보다 어그로를 끌어서 내용을 보게 만드는 거니깐"이라고 했다. 비교 대상은 다음과 같다.
- 지금 C: "고지서 오기 전에 / 우리 집 종부세 꼭 확인"
- 정보형 C2: "1주택 공시가 12억 넘으면 / 이번 달 종부세 고지서 옵니다"

**Why:** 썸네일이 조건과 답을 다 알려 주면 영상을 볼 이유가 줄어든다고 본다. 대본 v5의 "답은 인트로에서 말하지 않는다"와 같은 원리다.

**How to apply:**
- 썸네일 2줄은 궁금증, 긴급, 질문으로 끝내고, 구체적인 기준선이나 답은 숨긴다.
- 숫자는 궁금증을 만들 때만 쓴다(예: "+77% 아니면 -51%").
- 조사에서 나온 "대상·숫자를 콕 집기"는 이 원칙보다 아래에 둔다.
- 10 젠슨 황 A안 "젠슨 황 리스크 / 내 연금도 흔들린다?"가 이 방향이다.
